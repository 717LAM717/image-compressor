# JPG Photos Under 2MB

這是一個純前端 JPG 批次壓縮工具，適合網拍照片上架前使用。

## 功能

- 批次選取或拖曳 JPG / JPEG 照片
- 將每張照片壓縮到指定 MB 以下，預設為 2MB
- 可指定輸出寬度與高度
- 可選擇是否保持原始照片比例
- 可批次匯入後，逐張照片個別設定寬度、高度與是否保持比例
- 壓縮完成後產生 ZIP 檔下載
- 所有處理都在瀏覽器內完成，照片不會上傳到伺服器

## 使用方式

直接開啟 `index.html`，或部署到 GitHub Pages 後用網址開啟。

上方尺寸欄位是批次預設值，新加入的照片會套用這組設定。照片加入清單後，也可以在每一列個別修改寬度、高度與是否保持比例。

尺寸欄位可以留空。勾選「保持比例」時，填寬或高其中一個即可；寬高都填時，照片會等比例縮進該範圍內。取消勾選時，會依輸入的寬高輸出，照片可能變形。

## GitHub Pages 部署

1. 在 GitHub 建立一個新的 repository。
2. 上傳 `index.html`、`README.md`、`.nojekyll`。
3. 到 repository 的 Settings -> Pages。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`。
6. 儲存後等待 GitHub 產生網址。

## 注意

如果瀏覽器阻擋自動下載，請在壓縮完成後手動按畫面上的「下載 ZIP」按鈕。
