# 網拍照片上架助手

這是一個純前端 JPG 批次處理工具，適合電商照片上架前使用。所有處理都在瀏覽器內完成，照片不會上傳到伺服器。

幫你一次處理上架照片，不用一張張改、不用怕超過限制。

## 功能

- 批次選取或拖曳 JPG / JPEG 照片
- 每張照片都可以個別設定輸出尺寸
- 輸出 ZIP 檔下載
- 顯示處理前後的尺寸與檔案大小，方便比較

## 三種模式

### 僅調整尺寸

- 只改變圖片畫素尺寸
- 維持原圖比例
- JPEG 品質固定為 100%
- 不限制輸出檔案大小

### 僅壓縮容量

- 保持原始寬高不變
- 可輸入目標檔案大小，例如 1MB
- 也可用品質滑桿控制 JPG 品質
- 有填目標 MB 時，品質滑桿會作為品質上限

### 進階混合

- 可同時調整尺寸並限制檔案大小
- 適合電商主圖、細節圖需要同時控制解析度與容量時使用

## 使用方式

直接開啟 `index.html`，或部署到 GitHub Pages 後用網址開啟。

上方設定會作為批次預設值。照片加入清單後，也可以在每一列個別修改寬度、高度與是否保持比例。

## GitHub Pages 部署

1. 在 GitHub 建立或開啟 repository。
2. 上傳 `index.html`、`README.md`、`.nojekyll`、`logo.jpg`。
3. 到 repository 的 Settings -> Pages。
4. Source 選 `Deploy from a branch`。
5. Branch 選 `main`，資料夾選 `/root`。
6. 儲存後等待 GitHub 產生網址。

## 注意

如果瀏覽器阻擋自動下載，請在處理完成後手動按畫面上的「下載 ZIP」按鈕。
